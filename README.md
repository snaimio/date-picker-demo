## 📌 Technical Overview

**DatePicker Demo** showcases advanced date and time selection patterns in **SwiftUI**. It demonstrates graphical calendar pickers, wheel pickers, closed range validation constraints (past vs future date filtering), and localized date formatting.

---

## ✨ Key Features

- **Multiple Display Styles**: Compact, graphical calendar popup, and wheel picker presentations.
- **Closed Date Ranges (`...Date()`)**: Restrict selection boundaries to past, future, or custom date intervals.
- **Locale-Aware Formatting**: Output formatting utilizing Apple's modern Swift `FormatStyle` API.
